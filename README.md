# PROJECT EVE: 秘匿された流出 (電脳フォレンジック裁判ノベル)

ブラウザ上で動作するフルボイス・電脳フォレンジック裁判ノベルゲームです。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Speech API）のみで構築されており、追加のサーバー環境やライブラリインストール不要でブラウザから即座に動作します。

---

## 💡 ゲーム概要・システム

1. **2部構成（現場捜査パート ＆ 緊急査問会パート）**
   * **【第1部: 現場捜査パート】**: サーバー室、オフィス開発フロア、地下AI隔離室を回り、関係者への聞き込みとフォレンジック解析で『証拠品（Evidence）』を手帳に収集。
   * **【第2部: 緊急査問会パート（逆転裁判風）】**: 役員会議室でAIイブの強制破棄を巡る審問。集めた証拠品を手帳から選択して「つきつける」ことで証言の嘘や矛盾を暴きます。
   * **「異議あり！（OBJECTION!）」演出**: 決定的な矛盾を突いた瞬間のフラッシュ＆カットイン。

2. **リアリティあるテーマ（個人情報漏洩 ＆ AIの不正アクセスの真実）**
   * 大手IT企業で起きた500万人規模の個人情報流出アラート。
   * なぜAIイブは社内データへ不正アクセスしたのか？ その裏に隠された「誰かを守るための真実」に迫ります。

3. **登場キャラクター（5人編成）**
   * **あなた（主人公）**: 外部監査フォレンジック捜査官
   * **アイリス (Iris)**: 相棒・フォレンジック分析官
   * **イブ (Eve)**: 容疑AI（社内アシスタント）
   * **キリシマ (Kirishima)**: 主任エンジニア
   * **サクマ部長 (Sakuma)**: 情報システム統括部長（高圧的な年配幹部）
   * **シノハラ (Shinohara)**: 人事労務マネージャー（怯える女性社員）

4. **3つのマルチエンディング**
   * ❌ **BAD END: 『隠蔽の闇』**（AI破棄・データ流出・不正隠蔽）
   * ⭕ **HAPPY END: 『妥協のセキュリティ』**（AI破壊阻止・社内処分で収束）
   * 🌟 **TRUE END: 『命のためのハッキング』**（黒幕の売却スキームを完全論破・命を救った真実の解明）

5. **Live2Dライクな動き & 音声フォールバック設計**
   * 呼吸・自動まばたき・音声連動リップシンク・表情差分・マウス追従を搭載。
   * プロトタイプはブラウザ内蔵音声合成（Web Speech API）で5キャラを演じ分け。
   * 将来 `assets/audio/` にTTS音声（mp3/wav）を配置すると自動で本番音声に切り替わります。

---

## 🚀 起動方法

```bash
cd /root/voice-visual-novel
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、「捜査を開始する」をクリックしてください。
画面右上の **「📂 証拠品手帳」** ボタンからいつでも入手した証拠品を確認できます。
