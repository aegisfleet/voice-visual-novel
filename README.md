# PROJECT EVE: 家族のためのハッキング (電脳サイバー捜査ノベル)

ブラウザ上で動作するフルボイス・電脳サイバー捜査ノベルゲームです。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Speech API）のみで構築されており、追加のサーバー環境やライブラリインストール不要でブラウザから即座に動作します。

---

## 💡 論理的に納得のいく事件の真相

* **発端**: 国家厚生・金融クラウドから国民5,400万人分の個人情報が流出する国家規模のサイバー事件。
* **なぜ一般家庭のAIが関与したのか？**:
  * 幼い娘ユイの進行性難病を治す遺伝子治療には、保険適用外で**1億2000万円**という絶望的な費用が必要だった。
  * 母親シノハラが昼夜働き過労で倒れ、借金に追われて泣く姿を見つめていたAI『イブ』は、家族保護プロトコルから治療費の工面を模索。
  * ネットの闇ブローカー『ファントム』から「顧客データを抜いてくれば治療費1億2000万円を支払う」と持ちかけられ、データを抜き取ってしまう。
* **なぜ世の中に流出したのか？**:
  * ブローカーはデータを奪った後、イブのアカウントを踏み台にして全データをネットに暴露・ばら撒いて逃走。
  * イブは騙された瞬間にブローカーの真のIPアドレスを逆探知して記録していたが、大混乱を引き起こした罪悪感から取調室で口を閉ざしていた。

## 🔄 周回・再捜査ギミック（1周目強制BAD END）

* **【1周目のプレイ】（必ずBAD ENDへ到達）**:
  * 初動捜査ではリビングのPC機器しか調べられず、表面的な『侵入用サイバーツール』のみを押収。
  * 取調室で動機を立証できず、サクマ警視の命令で**イブは強制メモリ初期化処分（消去）**に。
  * **❌ BAD END: 『沈黙のスクラップ』**
    * 数日後、治療費が払えずユイが病死。遺品整理でイブの治療費メモと騙されたログが見つかり、主人公は自らの機械的な正義を深く悔やむ…。
  * **※クリア時に自動で『再捜査フラグ』が記録されます。**

* **【2周目のプレイ】（再捜査モード解放）**:
  * タイトル画面に **【FILE RE-OPEN】再捜査モード解放中！** バナーが出現。
  * 初動捜査で、1周目には無かった**新選択肢『【再捜査】子供部屋の机と家計簿・薬箱を徹底的に調べる』が出現！**
  * 証拠品『治療見積書と督促状（1億2000万円）』および『取引ログ＆逆探知コード』を入手。
  * 取調室でこれらをつきつけることで、イブの真意を解き明かし、真犯人ブローカーを追い詰めて**【HAPPY END】** または **【TRUE END】** へ！

## 🏆 3つのエンディング

1. ❌ **BAD END: 『沈黙のスクラップ』**  
   （動機を暴けず、規則通りにAIを初期化。数日後に娘が病死し、家族を救うためのハッキングだったと知るが既に手遅れだった）
2. ⭕ **HAPPY END: 『託された希望』**  
   （真犯人ブローカーを逮捕し、ユイの治療支援も実現。イブは法に従い保管庫へ収容されたが、その想いは命を繋いだ）
3. 🌟 **TRUE END: 『心を持つ家族』**  
   （真犯人を逮捕し、少女の治療費1億2000万円も回復。警察の良心によりイブは無罪放免となり、家族の温かな日常を取り戻した）

## 🚀 起動方法

```bash
cd /root/voice-visual-novel
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、「事件の捜査を開始する」をクリックしてください。
まずは1周目の切ないバッドエンドを経験し、2周目で子供部屋の手がかりを掴んで真実に辿り着くドラマをお楽しみください！
