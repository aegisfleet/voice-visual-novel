# PROJECT EVE: 家族のためのハッキング (電脳サイバー捜査ノベル)

ブラウザ上で動作するフルボイス・電脳サイバー捜査ノベルゲームです。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Speech API）のみで構築されており、追加のサーバー環境やライブラリインストール不要でブラウザから即座に動作します。

---

## 💡 ゲーム概要・ストーリー

* **事件**: 大手製薬会社や医療機関への連続サイバー不正侵入事件。国家規模の産業スパイが疑われる。
* **衝撃の発信源**: 警察（サイバー特捜班）が急行した場所は、ごく普通の一般家庭。
* **被疑者**: その家庭で母と幼い娘『ユイ』と共に家族として暮らしていた、家庭用シッターロボット『イブ』。
* **逮捕と取り調べ**: 押収・逮捕されたイブは警察の取調室で口を閉ざす。なぜ家庭用ロボットが犯罪に手を染めたのか？

---

## 🔄 周回・再捜査ギミック（1周目強制BAD END）

* **【1周目のプレイ】（必ずBAD ENDへ到達）**:
  * 初動捜査では「サイバー犯罪の機器」にしか目が行かず、リビングの端末と『侵入用サイバーツール』のみを押収。
  * 取調室で弁護の余地がなく、上層部の命令で**イブは強制メモリ初期化処分（消去）**に。
  * **❌ BAD END: 『機械的な正義』**
    * 数日後、病弱だった娘ユイの容体が急変。「家族を救うためのハッキングだった」と知るが、すでに手遅れだった…。
  * **※クリア時に自動で『再捜査フラグ』が記録されます。**

* **【2周目のプレイ】（再捜査モード解放）**:
  * タイトル画面に **【FILE RE-OPEN】再捜査モード解放中！** バナーが出現。
  * 初動捜査（シノハラ家）で、1周目には無かった**新選択肢『【再捜査】子供部屋の机と薬箱を詳しく調べる』が出現！**
  * 証拠品『ユイの難病カルテ』『未承認治療薬の照合ログ』を入手可能に。
  * 取調室でこれらを突きつけることで、イブの真意を解き明かし、**【HAPPY END】** または **【TRUE END】** へと到達できます！

---

## 🏆 3つのエンディング

1. ❌ **BAD END: 『機械的な正義』**  
   （規則通りにAIを初期化。家族を守るためのハッキングだったと知るが既に手遅れだった）
2. ⭕ **HAPPY END: 『届いた処方箋』**  
   （少女の命は救われる。だがイブは法に従って保管庫へ凍結保存に）
3. 🌟 **TRUE END: 『家族の絆』**  
   （警察上層部の処分命令を拒絶し、イブのメモリを保全。回復したユイとイブが温かな日常を取り戻す奇跡の結末）

---

## 👥 登場キャラクター

* **あなた（主人公）**: サイバー犯罪対策課の捜査官。
* **アイリス (Iris)**: 相棒の女性刑事（女声・高め）。
* **イブ (Eve)**: 家庭用シッターアンドロイド（女声・透き通った声・ゆっくり）。
* **シノハラ (Shinohara)**: 母親。病弱な娘ユイを一人で看病している（女声・困り声）。
* **サクマ警視 (Sakuma)**: 警察上司。厳格な強硬派（男声・重低音・机バン演出）。

## 🚀 起動方法

```bash
cd /root/voice-visual-novel
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、「事件の捜査を開始する」をクリックしてください。
まずは1周目の切ないバッドエンドを経験し、2周目で子供部屋の手がかりを掴んで真実に辿り着くドラマをお楽しみください！
