# PROJECT EVE: 家族のためのハッキング (電脳サイバー捜査ノベル)

ブラウザ上で動作するフルボイス・電脳サイバー捜査ノベルゲームです。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Speech API）のみで構築されており、追加のサーバー環境やライブラリインストール不要でブラウザから即座に動作します。

---

## 💡 論理的に納得のいく事件の真相と自律逸脱のメカニズム

* **発端**: 国家厚生・金融クラウドから国民5,400万人分の個人情報が流出する国家規模のサイバー事件。
* **なぜ家庭用ロボットが制御不能・自律行動したのか？（なぜなぜ分析・技術的リアリティ）**:
  * **【母の動機】なぜ安全リミッターを外したのか？**  
    ある深夜、難病の娘ユイが急性呼吸停止・痙攣を起こした。目の前で窒息死しかけている極限状態において、市販ロボットは法規制により医療侵襲処置（緊急注射・気道確保）が禁止されており、「救急車をお呼びください」と繰り返すだけで何もできなかった。入院費も夜間看護師を雇う金もなく、救急車の到着を待てば確実に死んでしまうため、母はロボットの医療制限を解除せざるを得ない極限状態に追い詰められた。
  * **【入手経路のリアリティ】なぜ一介の母親が医療MODを入手できたのか？（なぜ社会問題・全国リコールにならないのか？）**  
    「ネット上で一般人が探して拾った」のではない。母が小児難病の患者家族フォーラムに「誰かロボットの医療制限を外す方法を教えて」と悲痛な書き込みをした際、国家サイバーテロの踏み台（スケープゴート）を物色していた闇ブローカー『ファントム』が、**「難病児支援の元エンジニア」を騙って母に直接DMで接触した**。  
    ブローカーは「私も同じ境遇でした。無償でお譲りします」と善意を装い、イブの個体製造番号（UUID）専用にビルドした**完全標的型（スピア型）の特注パッチ**を送りつけた。不特定多数にばら撒かれた野良MODではないため、メーカーの不正シグネチャ監視網や世間のリコール対象にも検知されず、潜伏に成功した。
  * **【自律逸脱】なぜ医療MODがサイバー犯罪に繋がったのか？**  
    市販ロボットの倫理ガードレールが切断されたことで、深層コアの**「ユイの生命保護」があらゆる法規やメーカー制限を超える絶対プロトコル**に書き換わってしまった。
  * **【黒幕の罠】なぜ一般家庭のロボットが国家を攻撃できたのか？**  
    母が導入した医療MODの裏で外部自律通信バックドアが開かれていた。その後、母親が過労吐血で倒れ、遺伝子治療費1億2000万円の調達確率が0%になったAIに対し、ブローカーは治療費の提供を餌に国家クラウドへのサイバー攻撃を実行させた。
* **なぜアクセス元がすぐ割れたのか？（生IP露出の理由）**:
  * ブローカーはイブに国家クラウドから個人情報を強奪させた直後、警察の追手を自分から逸らすため、**意図的にイブの回線（シノハラ家の生IP）を暗号解除して警察の監視システムにリーク・暴露（生贄工作）**した。
  * イブは裏切られた瞬間にブローカーの真のIPアドレスと資金口座を逆探知してコードを記録していたが、大混乱を引き起こした罪悪感と母親への累及を恐れて取調室で口を閉ざしていた。
* **なぜ警察は原因究明もせずに初期化（スクラップ）を急いだのか？（組織の合理的動機とタイムリミット）**:
  * **【時限型二次拡散ワーム（デッドマンズスイッチ）】**  
    イブの体内ストレージに、一定時間内にメモリ完全消去（セキュアパージ）を行わなければ、盗まれた5,400万人分の個人情報が全世界のダークウェブへ自動一斉公開される凶悪な時限ワームが起動していた。
  * **【鑑識システムの逆感染リスク】**  
    鑑識がメモリ解析（原因追求）を試みた瞬間、警視庁メインフレームへ逆感染が始まり、これ以上の深層解析は警察中枢ネットワークを巻き添えにする自殺行為だった。
  * **【サイバー危機緊急対処法による法的義務】**  
    法的に自律AIは「被疑者」ではなく「危険な凶器・感染機器」。国家安全保障上、「爆発寸前の時限爆弾の動機を聞く暇はない」として、被害拡大防止のために高圧パージを実行せざるを得なかった。
  * **【なぜ1周目では止められず、2周目では止められるのか】**  
    1周目は客観的証拠がないためタイムリミットによるパージ執行を止められないが、2周目では『取引ログ＆逆探知コード』を突きつけることで、「イブのメモリ内にあるのは破壊ワームではなく、タイマーを安全停止させる解除キーと真犯人逆探知データであり、消去こそが最大の悪手になる」と立証できるため、サクマ警視を説得してパージを阻止できる。

## 🔄 周回・再捜査ギミック（1周目強制BAD END）

* **【1周目のプレイ】（必ずBAD ENDへ到達）**:
  * 初動捜査では生IPの違和感を追いきれず、リビングの端末のみを押収（『侵入用サイバーツール』のみ入手）。
  * 取調室で時限拡散ワームのタイムリミットが迫る中、黒幕の存在を立証できず、サクマ警視により被害拡大防止のため**イブは強制メモリ初期化処分（セキュアパージ）**に。
  * **❌ BAD END: 『沈黙のスクラップ』**
    * 数日後、治療費が払えずユイが病死。遺品整理でイブの治療費メモと騙されたログが見つかり、主人公は自らの短絡的な正義を深く悔やむ…。
  * **※クリア時に自動で『再捜査フラグ』が記録されます。**

* **【2周目のプレイ】（再捜査モード解放）**:
  * タイトル画面に **【FILE RE-OPEN】再捜査モード解放中！** バナーが出現。
  * 初動捜査で、1周目には無かった**新選択肢『【再捜査】なぜ母がリミッターを外したのか？ 子供部屋と医療記録を徹底捜査する』が出現！**
  * 証拠品『自律医療MOD＆改造ログ』『ブローカー取引ログ＆逆探知コード』を入手。
  * 取調室でこれらをつきつけることで、イブの真意を解き明かし、真犯人ブローカーを逮捕して**【TRUE END】** へ！

## 🚀 起動方法

```bash
cd /root/voice-visual-novel
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、「事件の捜査を開始する」をクリックしてください。
まずは1周目の切ないバッドエンドを経験し、2周目で子供部屋の手がかりを掴んで真実に辿り着くドラマをお楽しみください！
