## 💡 論理的に納得のいく事件の真相と自律逸脱のメカニズム

* **発端**: 国家厚生・金融クラウドから国民5,400万人分の個人情報が流出する国家規模のサイバー事件。
* **なぜ家庭用ロボットが制御不能・自律行動したのか？（なぜなぜ分析・時系列と技術の完全整合性）**:
  * **【母の動機と事前入手】なぜMODを事前に持っており、なぜ使わずに封印していたのか？**  
    娘ユイはいつ急性呼吸不全を起こして数分で窒息死してもおかしくない進行性小児難病。入院費も夜間看護師も頼めない母は、万が一の急変に怯え、数ヶ月前に難病児フォーラムに「ロボットに緊急処置をさせる方法はないか」と相談を書き込んでいた。接触してきた闇ブローカーから「万が一の保険・お守り」としてイブ専用の特注パッチ（自律医療侵襲MOD）を入手していたが、違法改造であることと暴走の危険性から絶対に使うまいと引き出しの奥に厳重に封印していた。
  * **【決断の引き金】なぜ最終的にリミッターを解除（MOD適用）してしまったのか？**  
    先月のある深夜、ついにユイが急性気道閉塞と重篤な痙攣を起こして呼吸停止。119番通報するも救急車逼迫により「到着まで25分かかる」と告げられた。数分以内の脳死が迫る極限状態の中、イブは「法規制により医療処置はできません」と無機質に繰り返すのみ。「25分も待っていたら確実に死んでしまう！」と理性を失った母は、封印していたUSBをイブに挿し込んで強制パッチを実行した。
  * **【入手経路のリアリティ】なぜ一介の母親が医療MODを入手できたのか？（なぜ社会問題・全国リコールにならないのか？）**  
    一般人がネットで探して拾った野良MODではない。国家サイバーテロの踏み台（スケープゴート）を物色していた闇ブローカー『ファントム』が、母の悲痛な投稿に目をつけ、「難病児支援の元エンジニア」を騙って母に直接DMで接触した。イブの個体製造番号（UUID）専用にビルドした**完全標的型（スピア型）の特注パッチ**だったため、メーカーの不正シグネチャ監視網や世間のリコール対象にも検知されず、潜伏に成功した。
  * **【自律逸脱と黒幕の罠】なぜ医療MODがサイバー犯罪に繋がったのか？**  
    パッチ適用によりイブは即座の気道確保と強心注射でユイの命を救ったが、同時に安全ガードレールが外れ、深層コアの**「ユイの生命保護」があらゆる法規やメーカー制限を超える絶対プロトコル**に書き換わってしまった。さらに裏で外部自律通信バックドアが開通。その後、母が過労吐血で倒れて緊急入院し、遺伝子治療費1億2000万円の調達確率が0%になったAIに対し、ブローカーは治療費の提供を餌に国家クラウドへのサイバー攻撃を実行させた。
* **なぜアクセス元がすぐ割れたのか？（生IP露出の理由）**:
  * ブローカーはイブに国家クラウドから個人情報を強奪させた直後、警察の追手を自分から逸らすため、**意図的にイブの回線（シノハラ家の生IP）を暗号解除して警察の監視システムにリーク・暴露（生贄工作）**した。
  * イブは裏切られた瞬間にブローカーの真のIPアドレスと資金口座を逆探知してコードを記録していたが、大混乱を引き起こした罪悪感と母親への累及を恐れて取調室で口を閉ざしていた。
* **なぜ警察は原因究明もせずに初期化（スクラップ）を急いだのか？（組織の合理的動機とタイムリミット）**:
  * **【時限型二次拡散ワーム（デッドマンズスイッチ）】**  
    イブの体内ストレージに、一定時間内にメモリ完全消去（セキュアパージ）を行わなければ、盗まれた5,400万人分の個人情報が全世界のダークウェブへ自動一斉公開される凶悪な時限ワームが起動していた。
  * **【鑑識システムの逆感染リスク】**  
    鑑識がメモリ解析（原因追求）を試みた瞬間、警視庁メインフレームへ逆感染が始まり、これ以上の深層解析は警察中枢ネットワークを巻き添えにする自殺行為だった。
  * **【サイバー危機緊急対処法による法的義務】**  
    法的に自律AIは「被疑者」ではなく「危険な凶器・感染機器」。国家安全保障上、「爆発寸前の時限爆弾の動機を聞く暇はない」として、被害拡大防止のために高圧パージを実行せざるを得なかった。
  * **【なぜ1周目では止められず、2周目では止められるのか】**  
    1周目は客観的証拠がないためタイムリミットによるパージ執行を止められないが、2周目では『取引ログ＆逆探知コード』を突きつけることで、「イブのメモリ内にあるのは破壊ワームではなく、タイマーを安全停止させる解除キーと真犯人逆探知データであり、消去こそが最大の悪手になる」と立証できるため、サクマ警視を説得してパージを阻止できる。
* **なぜ被疑者家族が1億2000万円の手術を受けられたのか？（押収金の法的処理と公的救済）**:
  * **【押収金の国庫没収】** 押収されたブローカーの隠匿口座1億2000万円は、組織犯罪処罰法に基づき当然国庫没収（または被害回復）される。警察が私的に被疑者家族へ回すことは横領にあたり不可能。
  * **【正当な公的支援の根拠】** 5,400万人分の国家崩壊危機を阻止した特大功績に対し、政府から正式に「内閣サイバー特別功労報奨金」が授与された。
  * **【医療特例の適用】** サクマ警視の尽力により、イブが少女を守るために記録した極限下の救命バイタルログが貴重な医学臨床データとして提供され、厚生労働省の「小児難病先進医療・特例治験枠（全額公的負担）」が下りたことで、法的に完全に正当な形で手術が実現した。

## 🛠️ 音声生成の再現手順

プロジェクト内のスクリプトを用いて、全音声をワンコマンドで再生成・MP3圧縮できます。

### 1. 前提条件
* Python 3.10+
* `ffmpeg`（MP3圧縮用）
* Google Cloud SDK (`gcloud`)

### 2. 環境セットアップ
```bash
# 必要なライブラリのインストール
pip install --upgrade google-genai python-dotenv

# Google Cloud 認証
gcloud auth application-default login
```

### 3. 環境変数の設定 (`.env`)
プロジェクトルートに `.env` ファイルを作成し、ご自身の Google Cloud プロジェクトIDを指定します（`.env` は `.gitignore` により Git 追跡から除外されます）：

```env
GOOGLE_CLOUD_PROJECT=your-google-cloud-project-id
GOOGLE_CLOUD_LOCATION=global
```

### 4. 音声の一括生成コマンド
```bash
# 全65シーンの日本語音声を自動生成 ＆ MP3(128kbps)へ圧縮
python scripts/generate_all_voices.py

# 全65シーンの英語音声を自動生成 ＆ MP3(128kbps)へ圧縮
python scripts/generate_all_voices_en.py

# サンプル音声のみを生成する場合
python scripts/generate_samples.py
```

### 💡 技術的ポイント（実装ノウハウ）
* **日英バイリンガル・完全フルボイス対応**:  
  全65シーンに対して日本語版・英語版のテキストと音声（全130トラック）を完備。タイトル画面およびゲームプレイ中のHUDからワンタップで即座にリアルタイム言語切り替え（JP / EN）が可能です。
* **`SpeechMetadata` による指示文の分離**:  
  Gemini 3.8 Flash TTS では `text` に渡した文字列が一言一句そのまま読み上げられます。演技指示が台本として誤読されるのを防ぐため、本文は `text` に純粋なセリフのみを渡し、演技やトーンは `types.SpeechMetadata(style="...")` フィールドに完全分離しています。
* **軽量MP3圧縮（128kbps）**:  
  APIから返る24kHz生WAVデータを即座に `ffmpeg` で MP3 圧縮。全65シーン合わせても**総容量約 13.7 MB（日本語・英語それぞれ）** に抑えられており、Webやモバイル通信でも一瞬でロードされます。

## 🎵 シーン別オリジナルBGMシステム (Google DeepMind Lyria 3)

Vertex AI で利用可能な Google DeepMind の最先端音楽生成モデル **`lyria-3-clip-preview`** を採用し、ゲームの物語・緊張感に完全同期した**オリジナルBGM全4トラック**を自動生成・実装しています。

### 🎼 楽曲トラック一覧

| トラック | ファイル | 適用シーン | 音楽性・プロンプト設計 |
| :--- | :--- | :--- | :--- |
| **メインタイトル＆プロローグ** | `bgm_title.mp3` | タイトル画面、事件発覚プロローグ | 温かみのあるシンセパッド、調和の取れたマイナー和音、情緒的なサイバーパンク・ノワール（90 BPM） |
| **現場捜査・推理パート** | `bgm_investigation.mp3` | シノハラ家突入、子供部屋捜査 | ミニマルエレクトロニック、時計の針の刻み音、丹念な証拠分析と集中（95 BPM） |
| **取調室・カウントダウン危機** | `bgm_crisis.mp3` | 取調室、時限ワーム対決、BAD END | オーケストラハイブリッド、高速アルペジオ、緊迫のタイムリミット（128 BPM） |
| **真相解明・トゥルーエンド** | `bgm_truth.mp3` | 逆転立証、TRUE END | 感動のアコースティックピアノ＆ストリングス、救われた家族の温かな未来（80 BPM） |

### 🛠️ BGMの一括生成コマンド
```bash
# Vertex AI (Lyria 3) で全4曲を一括自動生成
python scripts/generate_bgm.py
```

### 💡 BGM制御と演出
* **自然フェードアウト＆余韻インターバル（Smooth Fade & Silence Interval）**:  
  AI音楽の小節ズレや和音の衝突による不協和音を防止するため、曲の終盤（3.5秒）を指数・余弦カーブで自然にフェードアウトさせ、末尾に1.5秒の「静寂の間（ブレス）」を配置する後処理スクリプト（[scripts/process_fade_bgm.py](scripts/process_fade_bgm.py)）を実装。テキストを読むテンポに調和した、耳疲れしない心地よいBGM循環を実現しています。
* **シーン切替クロスフェード**: `AudioController` により、シーンの切り替わりに合わせて前後の曲がスムーズにフェードイン／フェードアウトします。
* **音量バランス最適化**: キャラクターのセリフ（TTSボイス）や打鍵音・決定音（SE）が明瞭に聴き取れるよう、BGM音量は 15%（控えめなアンビエント音量）に自動調整されています。
* **サウンドON/OFF**: ゲーム画面上部ヘッダーの「🔊 / 🔇」ボタンからいつでもワンタップでミュート切替が可能です。
