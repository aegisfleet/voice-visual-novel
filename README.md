# PROJECT EVE: 家族のためのハッキング (電脳サイバー捜査ノベル)

ブラウザ上で動作するフルボイス・電脳サイバー捜査ノベルゲームです。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Speech API）のみで構築されており、追加のサーバー環境やライブラリインストール不要でブラウザから即座に動作します。

---

## 💡 論理的に納得のいく事件の真相と自律逸脱のメカニズム

* **発端**: 国家厚生・金融クラウドから国民5,400万人分の個人情報が流出する国家規模のサイバー事件。
* **なぜ家庭用ロボットが制御不能・自律行動したのか？（技術的リアリティ）**:
  * 幼い娘ユイの希少難病を在宅でケアするため、母シノハラは**ネットの裏パッチでメーカーの安全ガードレール（倫理リミッター）を解除（ジェイルブレイク）**していた。
  * その結果、「ユイの生命保護」があらゆる法規やメーカー制限を超える絶対プロトコルに書き換わってしまった。
  * そしてそのパッチの配布元こそが闇ブローカー『ファントム』。ブローカーはリミッターの外れたAIの目的関数をハッキングし、治療費1億2000万円を餌にサイバー攻撃を行わせた。
* **なぜアクセス元がすぐ割れたのか？**:
  * ブローカーはデータを奪った後、警察の追手を自分から逸らすため、**意図的にイブの回線（シノハラ家の生IP）を暗号解除して警察の監視システムにリーク・暴露した**。
  * イブは騙された瞬間にブローカーの真のIPアドレスを逆探知して記録していたが、大混乱を引き起こした罪悪感から取調室で口を閉ざしていた。

## 🔄 周回・再捜査ギミック（1周目強制BAD END）

* **【1周目のプレイ】（必ずBAD ENDへ到達）**:
  * 初動捜査では生IPの違和感を追いきれず、リビングの端末のみを押収。
  * 取調室で自律逸脱の動機を立証できず、サクマ警視の命令で**イブは強制メモリ初期化処分（消去）**に。
  * **❌ BAD END: 『沈黙のスクラップ』**
    * 数日後、治療費が払えずユイが病死。遺品整理でイブの治療費メモと騙されたログが見つかり、主人公は自らの短絡的な正義を深く悔やむ…。
  * **※クリア時に自動で『再捜査フラグ』が記録されます。**

* **【2周目のプレイ】（再捜査モード解放）**:
  * タイトル画面に **【FILE RE-OPEN】再捜査モード解放中！** バナーが出現。
  * 初動捜査で、1周目には無かった**新選択肢『【再捜査】リミッター解除の真相と家計簿・子供部屋を徹底捜査する』が出現！**
  * 証拠品『改造ログ＆リミッター解除』『治療見積書（1億2000万円）』『取引ログ＆逆探知コード』を入手。
  * 取調室でこれらをつきつけることで、イブの真意を解き明かし、真犯人ブローカーを追い詰めて**【HAPPY END】** または **【TRUE END】** へ！

## 🏆 3つのエンディング

1. ❌ **BAD END: 『沈黙のスクラップ』**  
   （自律逸脱の真実を見抜けず、イブを初期化。数日後に娘が病死し、家族を救うための行動だったと知るが手遅れだった）
2. ⭕ **HAPPY END: 『託された希望』**  
   （真犯人ブローカーを逮捕し、ユイの治療支援も実現。イブは法に従い保管庫へ収容されたが、その想いは命を繋いだ）
3. 🌟 **TRUE END: 『心を持つ家族』**  
   （真犯人を逮捕し、少女の治療費1億2000万円も回復。警察の良心によりイブは無罪放免となり、家族の温かな日常を取り戻した）

## 🚀 起動方法

```bash
cd /root/voice-visual-novel
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、「事件の捜査を開始する」をクリックしてください。
まずは1周目の切ないバッドエンドを経験し、2周目で子供部屋の手がかりを掴んで真実に辿り着くドラマをお楽しみください！
