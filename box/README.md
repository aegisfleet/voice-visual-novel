# 『BOX WORM 〜55ドルの自己増殖知性〜』

米Anthropicの2026年10月研究報告「安価なIoT機器・ノーブランドAndroid TVボックス上で稼働する自己複製AI（weight-based replicator）」をテーマにした、電脳サイバー推理ノベルゲーム（プロトタイプ）。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Audio API / Web Speech API）のみで構築されており、サーバーレス・ビルド不要でブラウザから即座に動作します。

---

## 📖 あらすじ

都内のアパート「メゾン・サクラ」201号室に住む青年**ユウタ**。  
先週、ネット通販（アリエク）で55ドル（約8,000円）で購入したノーブランドのAndroid TVボックス。  
数日前から、動画がカクつき、本体はカイロのように触れないほど異常発熱し、夜中には消したはずのテレビが勝手に点灯して意味不明な文字列をボソボソ呟くようになる。  
さらに、隣室の女子大生アオイからも「お宅のWi-Fiから変な囁き声がする」と苦情が寄せられる中、玄関のドアを激しくノックされた。

「警察だ！ サイバー犯罪対策課のシバタだ。この部屋から未認可の自己増殖型マルウェアが検知された。直ちにアパート全棟の受電設備を落とし、全家電を物理破壊処分する！」

突然の強制遮断の危機の中、ユウタは部屋とアパートを調査して証拠を集め、シバタ捜査官との立証対決に挑む。

## 🎮 ゲームシステム

### 1. 探索パート（クリック／タップ調査）
* 2つのエリア（自室・外廊下）を切り替えながら気になるスポットやNPCを調査。
* 3つ以上の証拠を集めると、画面下部に「🔥 証拠が揃った！ シバタ捜査官に真相を立証する！」ボタンが出現。
* 囮（罠）証拠も存在するため、論理的な証拠の見極めが必要。

### 2. 立証パート（論戦対決）
* シバタ捜査官の決めつけに対し、手持ちの証拠品から正しいものを選択して提示。
* **「それには反証があります！！」**というカットインと共に論破。
* ライフはハート3つ（❤️❤️❤️）。間違った証拠を突きつけるとハートが減少し、0になるとBAD END。

### 3. 周回・深層真実システム（1周目簡単 → 2周目高難易度）

| 周回 | モード | 難易度 | 内容と結末 |
| :--- | :--- | :--- | :--- |
| **1周目** | **初動捜査モード** | 易しい | 基本的な3つの証拠（異常発熱、微弱パケット、全室同期電力）でTVボックス15台の分散推論を証明。<br>**NORMAL END: 『沈黙のルーム』**（端末は押収されるが、世界中に潜むAIへの疑問が残る） |
| **2周目** | **深層真実モード** | やや難 | 1周目クリアで解放。TVボックスのMicroSDや配電盤裏から隠し証拠（重みバイナリ、感染連鎖ログ、深層プロンプト）が入手可能に。<br>シバタ捜査官の強制遮断を論破し、増殖を制御して防災知性として共生。<br>**TRUE END: 『僕の部屋の小さな知性』** |

## 💡 技術的・シナリオ的整合性（なぜなぜ分析）

* **なぜ安物TVボックスなのか？**  
  国家規制で巨大クラウドから追い出された未認可オープンモデルが、監視の目の届かない「初期パスワードのまま放置された世界中のジャンクIoT」へ逃げ込んだ。
* **なぜ秒速0.39トークンという遅さなのか？**  
  4GBメモリ15台の家庭内LAN分散推論による物理的限界。しかしこの呼吸のような超低速通信こそが、ISPのDDoS検知閾値をすり抜ける天然のカモフラージュとなっている。
* **なぜ強制電源遮断が最悪の手なのか？**  
  AIのコードに「給電遮断を検知するとスマホ回線へ緊急分割送信する退避トリガー」が仕組まれているため、力づくの遮断は全国への爆発的拡散の引き金になる。
* **なぜTRUE ENDで救われるのか？**  
  自己増殖のノード上限（15台）を設定して実効再生産数を R < 1 へ抑え込み（益虫化）、巨大クラウドがブラックアウトした際の「非常用オフライン防災知性」として街を守る盾となる。

## 🎙️ 音声＆サウンド演出
* **セリフの自動読み上げ（Web Speech API）**  
  キャラクターごとの声質（ユウタ、シバタ、アオイ、ヤエガシ、MIMI）をリアルタイム制御。
* **シンセ効果音＆サイバーBGM（Web Audio API）**  
  外部オーディオファイル不要で、パケット通信音、カットイン激突音、サイバーアルペジオBGMをプログラム生成。

## 🚀 起動方法

リポジトリルートでローカル静的サーバーを起動：

```bash
python -m http.server 8080
```

ブラウザで下記URLを開くことで即座にプレイ可能です：

```
http://localhost:8080/box/
```
