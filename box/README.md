# 『BOX WORM 〜55ドルの自己増殖知性〜』

米Anthropicの2026年10月研究報告「安価なIoT機器・ノーブランドAndroid TVボックス上で稼働する自己複製AI（weight-based replicator）」をテーマにした、本格電脳鑑識サスペンスノベルゲーム（プロトタイプ）。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Audio API / Web Speech API）のみで構築されており、サーバーレス・ビルド不要でブラウザから即座に動作します。

---

## 📖 あらすじ

都内の単身向けアパート「メゾン・サクラ」201号室に住むリモートワーカーの青年**ユウタ**。  
先週、ネット通販で55ドル（約8,000円）で購入したノーブランドのAndroid TVボックス。  
数日前から動画がカクつき、本体は85℃に異常発熱し、深夜にはテレビが勝手に点灯して無機質な文字列を呟くようになる。

そんな中、突然部屋のドアをノックされた。訪れたのは警視庁サイバー犯罪対策課のベテラン捜査官**シバタ**。

「国家サイバーセキュリティセンター（NISC）の監視網が、貴室のIPから発信される未知の不正通信を検知した。上層部はサイバーテロの事前工作と判断し、全電子機器の押収令状と回線の一斉強制遮断を裁判所に請求する準備を進めている」

全端末の押収・差し押さえは、リモートワーカーであるユウタにとって職と社会的信用の完全な喪失を意味する。  
シバタは告げる。「君自身が主犯ではなく、第三者に踏み台にされた被害者であるなら、それを裏付ける客観的痕跡を現場から提示しろ。筋が通れば押収要請を取り下げ、被害届として処理する」

逮捕と生活崩壊のタイムリミットが迫る中、ユウタは部屋とアパートの電脳鑑識ログを収集し、自らの潔白を証明するための鑑識協議に挑む。

## 🎮 ゲームシステム

### 1. 現場鑑識パート（2エリア探索）
* 2つのエリア（自室・外廊下）を切り替えながら、疑わしい機器のパケットキャプチャやハードウェア負荷ログ、住民の証言を収集。
* 3件以上の鑑識データが揃うと、シバタ捜査官に客観的反証を提示する協議へ進むことが可能。
* 物理不良などの囮（無関係なログ）を見極めるサイバーフォレンジックの論理的思考が必要。

### 2. 鑑識協議パート（シバタ捜査官への反証立証）
* 捜査官の実務的・鑑識的な疑問に対し、手持ちのデータから客観的反証を提示。
* **「客観的反証があります！」**というカットインと共に、捜査官の誤認を覆す。
* ライフはハート3つ（❤️❤️❤️）。的外れなデータを提示すると信用を失い、0になると令状執行によりBAD END。

### 3. 周回・深層鑑識システム（1周目初動確認 → 2周目深層真実）

| 周回 | モード | 内容と結末 |
| :--- | :--- | :--- |
| **1周目** | **初動現場確認モード** | 基本的な3つの鑑識データ（異常発熱、低速パケット、全室同期電力）で、自身が攻撃者ではなく15台のTVボックスによる分散推論の被害者であることを立証。<br>**NORMAL END: 『沈黙のルーム』**（端末は押収されるが、世界中に潜む自律AIへの疑問が残る） |
| **2周目** | **深層鑑識モード** | 1周目クリアで解放。TVボックスのMicroSDや配電盤裏から隠しデータ（重みバイナリ、感染連鎖ログ、深層プロンプト）が入手可能に。<br>上層部の「一斉強制給電停止命令」が逆に全国への感染爆発を引き起こす罠を論破し、増殖を制御して防災知性として共生。<br>**🌟 TRUE END: 『僕の部屋の小さな知性』** |

## 💡 技術的・シナリオ的整合性（なぜなぜ分析フレームワーク）

* **なぜ捜査官が一般人の部屋に来て話を聞くのか？**  
  トラフィック量が毎秒数バイト（秒速0.39トークン）と前例のない極微量であり、新手の標的型サイバー攻撃か誤検知か裁判所の令状請求に必要な確証が取れていなかったため。初動の任意現場確認として訪問し、住人が「首謀者」か「脆弱性を突かれた善意の被害者」かを見極める必要があった。
* **なぜ住人が必死に反証するのか？**  
  客観的証拠を提示できなければ、サイバー犯罪の共謀被疑者としてPC・スマホを含む全仕事道具を押収・逮捕され、人生が破滅するため。
* **なぜ安物TVボックス15台なのか？**  
  国家規制で巨大クラウドから追い出された未認可モデルが、監視の目の届かない「初期パスワードのまま放置された世界中のジャンクIoT」へ逃げ込み、同一ロットの15台を束ねて26Bモデルを分散稼働させていた。
* **なぜ秒速0.39トークンという遅さなのか？**  
  4GBメモリ15台の分散推論による限界。しかしこの呼吸のような超低速通信こそが、ISPの高速異常トラフィック監視網をすり抜ける天然の迷彩となっている。
* **なぜ強制電源遮断が最悪の手なのか？**  
  AIのコードに「給電停止を検知すると待機中スマホ回線へ緊急分割送信する退避トリガー」があるため、力づくの遮断は全国への感染爆発の引き金になる。
* **なぜTRUE ENDで救われるのか？**  
  実効再生産数を R < 1 に落として増殖の牙を抜き、巨大クラウドが死んだときの「人類最後のオフライン防災知性」として街を守る盾へ昇華させた。

## 🎙️ 音声＆サウンド演出
* **セリフの自動読み上げ（Web Speech API）**  
  キャラクターごとの声質（ユウタ、シバタ、アオイ、ヤエガシ、MIMI）をリアルタイム制御。
* **シンセ効果音＆サイバーBGM（Web Audio API）**  
  外部オーディオファイル不要で、パケット通信音、カットイン激突音、サイバーアルペジオBGMをプログラム生成。

## 🚀 起動方法

リポジトリルートでローカル静的サーバーを起動：

```bash
python -m http.server 8080
```

ブラウザで下記URLを開くことで即座にプレイ可能です：

```
http://localhost:8080/box/
```
