# 『ひだまりベンチ占拠事件 〜消えたクッションとボス猫の秘密〜』

ポメラニアンが主人公のほのぼの系推理ノベルゲーム（プロトタイプ）。  
Web標準技術（HTML5 / CSS3 / JavaScript / Web Audio API / Web Speech API）のみで構築されており、サーバーレス・ビルド不要でブラウザから即座に動作します。

---

## 🐾 あらすじ
秋晴れの夕暮れ、大好きな飼い主さんと一緒に「ひだまり公園」へ散歩にやってきた白ポメラニアンの**ポメ**。  
しかし、公園の一等地である特等席ベンチから町内会特製の「ふかふか座布団クッション」が忽然と姿を消す事件が発生！  
公園を仕切るボス猫**トラ吉**率いる猫集団は、「犬どもが嫌がらせで隠したに違いない」「犬は立ち入り禁止ニャ！」とポメたちを締め出そうとする。  
ポメはお散歩コースを取り戻すため、公園内を散歩しながら証拠を集め、猫集会で真相を暴くための論戦に挑む。

---

## 🎮 ゲームシステム

### 1. 探索パート（クリック／タップ調査）
* 公園マップ上の気になるオブジェクトをクリック（タップ）して調査。
* ポメが駆け寄り、愛らしいリアクションと共に手がかりを発見。
* 3つの基本証拠を揃えると、画面下部に「🔥 証拠が揃った！猫集会へ乗り込む！」ボタンが出現。

### 2. 立証パート（猫集会・論戦対決）
* 相手（ボス猫 トラ吉）の言いがかりに対して、手持ちの証拠品から正しいものを選択して提示。
* **「ワンッ！！！」**という気迫のカットインと共に論破。
* ライフはハート3つ（❤️❤️❤️）。間違った証拠を突きつけるとハートが減少し、0になるとBAD END。

### 3. マルチエンディング分岐

| エンディング | タイトル | 分岐条件 | 結末 |
| :--- | :--- | :--- | :--- |
| **BAD END** | **『しょんぼりお散歩帰り』** | 立証パートでライフが0になる | 猫たちの威嚇に圧倒され、しょんぼり退散（リトライ可能） |
| **HAPPY END** | **『ひだまりの和解』** | 1周目で3つの問答を完答する | 真犯人（シマリスのチビ）が判明し、犬猫なかよくベンチをシェア |
| **TRUE END** | **『もふもふレスキュー隊』** | 2周目以降、隠し証拠を入手して立証完答 | トラ吉の秘密と子猫たちを守り、ポメが「名誉ボス犬」に就任 |

## 🎙️ 音声＆サウンド演出
* **心の声の自動読み上げ（Web Speech API）**  
  * ブラウザ標準の日本語音声合成エンジンを使用し、キャラクターごとの声質（ポメ：高音で元気、トラ吉：低音でボス気質）をリアルタイム制御。
  * ヘッダーの「🗣️ 音声: ON/OFF」ボタンでいつでも切り替え可能。
* **シンセ効果音（Web Audio API）**  
  * 音声ファイル不要で、ポメの鳴き声（キャン！/ワン！）、トラ吉の鳴き声（ニャ〜ン）、キラリン発見音、激突カットイン音をプログラム生成。
* **ほのぼのBGM（Web Audio API）**  
  * 心地よい穏やかなコード進行のアルペジオをバックグラウンドで自動演奏。

## 🚀 起動方法

リポジトリルートでローカル静的サーバーを起動：

```bash
python -m http.server 8080
```

ブラウザで下記URLを開くことで即座にプレイ可能です：

```
http://localhost:8080/pome/
```
