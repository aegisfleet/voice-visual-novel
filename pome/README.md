# 『ひだまりベンチ占拠事件 〜消えたクッションとボス猫の秘密〜』

オレンジセーブル（茶色）で黒い口元がチャームポイントのポメラニアン「**パム**」が主人公の、初心者にもやさしいほのぼの推理ノベルゲーム。  
Web標準技術（HTML5 / CSS3 / SVGアニメーション / JavaScript / Web Audio API / Web Speech API）のみで構築されており、サーバーレス・ビルド不要でブラウザから即座に動作します。

---

## 🐾 あらすじ
秋晴れのぽかぽか陽気、大好きな飼い主さんと一緒に「ひだまり公園」へお散歩にやってきた、茶色いふわふわ毛並みに黒い口元（黒マズル）のポメラニアン**パム**。  
しかし、公園の特等席ベンチから「青いふかふか座布団」が忽然と姿を消す事件が発生！  
公園を仕切るボス猫**トラ吉**率いる猫集団は、「犬どもがいたずらで隠したに違いないニャ！犬は立ち入り禁止ニャ！」とパムたちを締め出そうとします。  
パムは大好きなお散歩コースを取り戻すため、2つのエリア（「ひだまり広場」と「ケヤキの森」）をトコトコ歩いて手がかりとお話を集め、猫集会で真相を解き明かします。

---

## 🎨 特徴：全キャラクターSVG表現＆SVGパーツアニメーション
* **主人公「パム」（オレンジセーブル＆黒マズル）**:
  * 茶色〜オレンジ系のグラデーション毛並み、黒い口元（黒マズル）、ティールグリーンの探偵スカーフをまとったオリジナルSVGデザイン。
* **全登場キャラクターの完全SVG化**:
  * パム、ボス猫トラ吉、管理人のおじいさん、ハトのポッポ師匠、見張り猫クロ、シマリスのチビ、三毛猫ミケ、子猫たち、飼い主さんまで全員を専用ベクターSVGで描画。
* **SVGパーツ単位のアニメーション表現**:
  * **耳ピコピコ＆尻尾フリフリ**: `<g class="svg-ear-l">`, `<g class="svg-ear-r">`, `<g class="svg-tail">` が感情に合わせて独立してスイング。
  * **自然な目パチ（自動瞬き）**: `<g class="svg-eyes-blink">` による定期的なまばたきアニメーション。
  * **発話連動の口パク（リップシンク）**: セリフ表示・読み上げ中に `<g class="svg-mouth">` が連動して開閉。
  * **首かしげ＆SVGベクターエフェクト**: 考え中の首かしげ（`thinking`）や、キラキラ・ハート・汗などのベクターエフェクトが滑らかにアニメーション。

## 🎮 ゲームシステム（ゲーム初心者にもやさしい設計）

### 1. 探索パート（2エリア移動＆未調査ガイド）
* 「🪑 ひだまり広場」と「🌲 ケヤキの森＆水飲み場」の2エリアを行き来して探索。
* エリア切替ボタンに**「重要手がかりの残り数バッジ」**が表示されるため、どこを調べればいいか迷いません。
* 気になる場所や動物をタップすると、ミニパムがトコトコ歩いて駆け寄ります。

### 2. 立証パート（猫集会・パムの推理メモ付き）
* トラ吉の言いがかりに対して、集めた証拠カードから1つを選んで提示します。
* 証拠カードをタップすると**「💡 パムの推理メモ（または ⚠️ 寄り道アイテム注意メモ）」**が表示されるため、推理ゲームが初めての方でも安心して正解を選べます。
* 「🔍 公園の探索に戻る」ボタンで、いつでも猫集会から公園の探索へ戻ることができます。

### 3. マルチエンディング分岐

| エンディング | タイトル | 分岐条件 | 結末 |
| :--- | :--- | :--- | :--- |
| **BAD END** | **『しょんぼりお散歩帰り』** | 立証パートでライフが0になる | トラ吉を論破できず一時退散（証拠を保持したまま即リトライ・再調査可能） |
| **HAPPY END** | **『ひだまりの和解』** | 1周目で3つの問答を突破する | 真犯人（シマリスのチビ）が判明し、犬猫なかよくベンチでお昼寝 |
| **TRUE END** | **『もふもふレスキュー隊』** | 2周目以降、隠し証拠を入手して最終追及を突破 | トラ吉が守っていた迷子の子猫たちをパムの毛並みで温め、「名誉ボス犬」に就任 |

## 🚀 起動方法

リポジトリルートでローカル静的サーバーを起動：

```bash
python -m http.server 8080
```

ブラウザで下記URLを開くことで即座にプレイ可能です：

```
http://localhost:8080/pome/
```
