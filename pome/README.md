# 『ひだまりベンチ占拠事件 〜消えたクッションとボス猫の秘密〜』

オレンジセーブル（茶色）で黒い口元がチャームポイントのポメラニアン「**パム**」が主人公の、初心者にもやさしい**1周完結・ほのぼの推理ノベルゲーム**。  
Web標準技術（HTML5 / CSS3 / SVGアニメーション / JavaScript / Web Audio API / Web Speech API）のみで構築されており、サーバーレス・ビルド不要でブラウザから即座に動作します。

---

## 🐾 あらすじ
秋晴れのぽかぽか陽気、大好きな飼い主さんと一緒に「ひだまり公園」へお散歩にやってきた、茶色いふわふわ毛並みに黒い口元（黒マズル）のポメラニアン**パム**。  
しかし、いつもみんなで日向ぼっこしていた公園の特等席ベンチから「青いふかふか座布団」が忽然と姿を消す事件が発生！  
公園を仕切るボス猫**トラ吉**率いる猫集団は、「おこげ口のパム公！犬どもがいたずらで隠したに違いないニャ！無実の証拠を集めてきてみろニャ！」とベンチの裏を隠すように通せんぼします。  
パムは犬たちの疑いを晴らすため、2つのエリア（「ひだまり広場」と「ケヤキの森」）をトコトコ歩いて手がかりとお話を集め、猫集会で**「事件の犯人」と「その裏に隠された心温まるサプライズの真実」**を解き明かします。

---

## 🌟 シナリオの特徴（1周完結・二段構えの真相と感動エピソード）
* **ループ不要のシンプルな1周完結構成**:
  * 周回（ループ）前提の分岐をなくし、1回のプレイ（全4問の猫集会）で「表の事件解決」から「裏の真実の解明」、そして感動のハッピーエンドまで一気に到達できる構成です。
* **「表の事件」と「裏の真実」が1本の必然で繋がるミステリー**:
  * **表の解決（問答1〜3）**: ベンチの隙間（1.5cm）の綿と青い糸、管理人さんの朝10時の穴掘り証言、ケヤキの高さ2.2mのウロから、座布団の布を前歯で切って綿を木の上に運んだのが**シマリスのチビ**であることを立証します。
  * **裏の真実（最終追及・問答4）**: 「木の上にあったのは中身の綿と端切れだけ。では青い座布団の本体はどこへ消えたのか？」という疑問から、ベンチ裏のダンボールで見つけた『鈴リボン付きの青いお守り袋』を提示します。
  * **感動のエピソード（『おこげ口の英雄と青いお守りの約束』）**:
    1. **旅立つ子猫たちへの「パムのにおい」のお守り**: 先週の大雨の日にパムが助けた迷子の子猫たちに遠くの街の里親が見つかり、今日の夕方5時に公園を旅立つことになっていました。「パム兄ちゃんのにおいがしないと寂しくて眠れないミャ」と泣く子猫たちのため、毎日パムが座ってぽかぽかのにおいが一番染み込んでいた「ベンチの青い座布団」を管理人さんから譲り受け、お守りポシェットに仕立て直していたのです。
    2. **「おこげ口」の呼び名に込められた誇りと感謝の勲章**: トラ吉たちがパムを「おこげ口」と呼んでいたのは、パムの黒い口元をからかっていたのではなく、大雨の日に鼻先を真っ黒な泥だらけにして子猫たちを救い出した「小さな英雄の勲章」という意味でした。残りの青い布で作られていた『名誉ボス犬の勲章バンダナ』が完成するまでパムをベンチ裏に近づけず、かつお別れの時間まで公園に引き留めておくため、トラ吉はわざと「座布団事件の挑戦状」で足止めしていたことが明かされます。

## 🎨 特徴：全キャラクターSVG表現＆SVGパーツアニメーション
* **主人公「パム」（オレンジセーブル＆黒マズル）**:
  * 茶色〜オレンジ系のグラデーション毛並み、黒い口元（黒マズル）、ティールグリーンの探偵スカーフをまとったオリジナルSVGデザイン。
* **全登場キャラクターの完全SVG化**:
  * パム、ボス猫トラ吉、管理人のおじいさん、ハトのポッポ師匠、見張り猫クロ、シマリスのチビ、三毛猫ミケ、子猫たち、飼い主さんまで全員を専用ベクターSVGで描画。
* **SVGパーツ単位のアニメーション表現**:
  * **耳ピコピコ＆尻尾フリフリ**: `<g class="svg-ear-l">`, `<g class="svg-ear-r">`, `<g class="svg-tail">` が感情に合わせて独立してスイング。
  * **自然な目パチ（自動瞬き）**: `<g class="svg-eyes-blink">` による定期的なまばたきアニメーション。
  * **発話連動の口パク（リップシンク）**: セリフ表示・読み上げ中に `<g class="svg-mouth">` が連動して開閉。
  * **首かしげ＆SVGベクターエフェクト**: 考え中の首かしげ（`thinking`）や、キラキラ・ハート・汗などのベクターエフェクトが滑らかにアニメーション。

## 🎮 ゲームシステム（ゲーム初心者にもやさしい設計）

### 1. 探索パート（2エリア移動＆未調査ガイド）
* 「🪑 ひだまり広場」と「🌲 ケヤキの森＆水飲み場」の2エリアを行き来して探索。
* エリア切替ボタンに**「重要手がかりの残り数バッジ」**が表示されるため、どこを調べればいいか迷いません。
* 気になる場所や動物をタップすると、ミニパムがトコトコ歩いて駆け寄ります。

### 2. 立証パート（猫集会・パムの推理メモ付き・全4問）
* トラ吉の言いがかりに対して、集めた証拠カードから1つを選んで提示します。
* 証拠カードをタップすると**「💡 パムの推理メモ（または ⚠️ 寄り道アイテム注意メモ）」**が表示されるため、推理ゲームが初めての方でも安心して正解を選べます。
* 「🔍 公園の探索に戻る」ボタンで、いつでも猫集会から公園の探索へ戻ることができます。

### 3. エンディング構成（シンプルな1周完結）

| エンディング | タイトル | 条件 | 結末 |
| :--- | :--- | :--- | :--- |
| **RETRY (BAD END)** | **『しょんぼりお散歩帰り』** | 立証パートでライフが0になる | トラ吉を論破できず一時退散（集めた証拠を保持したまま即リトライ・再調査可能） |
| **HAPPY END** | **『おこげ口の英雄と青いお守りの約束』** | 全4問の立証・最終追及を突破する | 消えた座布団に隠された「旅立つ子猫たちへのお守り」と「パムへの感謝の勲章バンダナ」のサプライズが判明し、名誉ボス犬としてみんなでお昼寝 |

## 🚀 起動方法

リポジトリルートでローカル静的サーバーを起動：

```bash
python -m http.server 8080
```

ブラウザで下記URLを開くことで即座にプレイ可能です：

```
http://localhost:8080/pome/
```
