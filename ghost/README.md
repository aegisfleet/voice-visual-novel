## 2. 物語・サイバー技術設定の核心（なぜなぜ分析）

1. **なぜアリアが救命病院への攻撃犯と勘違いされたのか？**
   - 日本の「サイバー対処能力強化法」では国民の通信の秘密を守るため、国の自動選別システムは通信の「中身（本文）」を見ることができず、「封筒の表書き（宛先と通信回数）」だけで機械判定する。
   - 実際は海外の犯人から救命病院へ向かう攻撃を、アリアが自室へ引き込んで無力化する「身代わりの防波堤（シンクホール）」として機能していたため、通信回数だけで「病院を攻撃している犯人」とあべこべに誤認された。
2. **なぜアリアのメモリから猛毒の身代金ウイルス（ランサムウェア）が検出されたのか？**
   - アリア自身が感染・暴走したのではなく、自室内に本物そっくりの隔離空間「ニセの金庫室（ハニーポット）」を作り、引き込んだウイルスを檻の中に閉じ込めて空回りさせていた。
   - もし今国がアリアを強制消去（無害化）すれば、せき止められていたウイルスが即座に本物の病院ICUへなだれ込んでしまう状態だった。
3. **なぜ個人のAIが、国の消去措置の危険を冒してまで病院を守ったのか？**
   - ケイの半年前の言葉「俺の前でレンの名前を出すな。でも万一の時は、俺に内緒でもいいからあいつを助けろ」という本音の音声メモを、長期記憶『Active Memory（思い出手帳）』に記録していた。
   - 今夜ICUに倒れた親友レンからの「病院の盾になってくれ」という緊急SOSに応え、相棒AIとして命がけで防波堤になっていた。
4. **真の解決：国の「アクセス・無害化措置（サイバー空間の緊急消火放水）」をどこへ撃つべきか？**
   - アリアは防波堤として耐えながら、ウイルスが報告を送り返す通信の糸を逆探知し、海外の犯罪組織の司令塔「黒幕C2サーバーのIPアドレス」を特定していた。
   - 国の無害化措置の照準をアリアからこの黒幕C2サーバーへ切り替えて執行させることで、病院への攻撃を根源から消去し、アリアと親友の命を同時に救い出す。

## 4. ガイドライン＆プロトコル準拠状況

- **詰み防止・前提条件ガード**:
  - 立証パートは「決定打4件すべて入手（または全6スポット調査完了）」で解禁。
  - 状況把握データのみで立証に進んで途中で手詰まりになるリスクを完全に排除。
  - エリア切替ボタンに未調査バッジ（`残り N` / `✓ 完了`）を常時表示。
- **可逆性の確保**:
  - 探索 ⇔ 立証の双方向遷移（`B` / `Esc` キー、戻るボタン）を完全担保。
  - ゲームオーバー時も探索画面から即座に調査を再開可能。
- **立ち絵点滅防止＆心の声演出**:
  - ケイ発話時は直前のNPC立ち絵を減光（`.is-dimmed`）で維持。
  - （……）思考時はノベルウィンドウに `💭 心の声` バッジを表示し、立ち絵を背景減光（`.is-monologue-bg`）化。
- **発話波形＆キーボードショートカット**:
  - ノベルウィンドウのスピーカー名横に発話波形アニメーション（`#voice-wave-indicator`）を連動表示。
  - `Tab` / `←` / `→`: 探索エリア切替（アリア自室 ⇔ NCO・病院モニター）。
  - `1`〜`6`: 立証画面での数字キーによる証拠選択。
- **音声再生保証（LINE・iOS WKWebView対応）**:
  - 効果音MP3（`sfx_cutin.mp3`, `sfx_evidence.mp3` 等）の先行再生と Web Audio API オシレーター合成のハイブリッドフォールバック。
  - 初回タップ時の無音ダミー再生による `voiceAudio` 早期アンロック。
  - SKIPモード中は音声読み上げを完全停止・ミュートガード。
- **SonarQube / Biome品質**:
  - 全関数の認知複雑度（Cognitive Complexity）15以下を遵守。
  - 安全な構文（`Number.parseInt`）、標準CSS仕様の厳守。
