本作品は、自律型パーソナルAIエージェントと日本の「能動的サイバー防御（サイバー対処能力強化法・同整備法）」をテーマにした、フルボイス・電脳鑑識＆逆転立証ビジュアルノベルゲームのプロトタイプです。

## 2. 物語・技術設定の核心（なぜなぜ分析）

1. **なぜシステムプロンプトの防御は破られなかったのか？**
   - サイトに命令文（プロンプト）は一切なく、Web標準の構造化データ（JSON-LD）内の在庫照会URLが電力網のIPにすり替えられていた（セマンティックSSRF）。AIは正当なデータ取得手続きとしてアクセスしたため、プロンプト防御を正常に通過した。
2. **なぜ執拗なファジング攻撃に見えたのか？**
   - 自律機能『Active Goal』の開発者システムプロンプトに「エラー時はクエリを補正して最大30回まで自動再試行せよ」と義務付けられていたため、忠実に再試行を繰り返した結果が攻撃シグネチャと合致した。
3. **なぜ監視層『Aegis Gate』は通過したのか？**
   - Aegis GateはWrite（書き込み・変更）をシステム遮断するが、Read（HTTP GET）は許可する設計だったため。
4. **なぜ国家サイバー統括室（NCO）は無害化パケットを撃ち込んだのか？**
   - 通信の秘密保護のため、自動選別システムはチャット本文やAIの思考ログを見られず、機械的波形情報のみでAPTインフラ攻撃と判定したため。
5. **Phase 1 と Phase 2 の二段構え解決**:
   - **Phase 1**: アリアが無害なRead権限下で正規プロンプトに従っていた被害端末であることを立証し、押収・初期化を阻止（NORMAL END）。
   - **Phase 2**: 翌朝8時に国内10万台のAIが一斉リトライを起こすマス・トラップに気づき、真犯人C2サーバーのオリジンIPを特定して本物の「アクセス・無害化措置」を国に執行させる（TRUE END）。

## 3. ガイドライン準拠状況

- **可逆性の確保**: 探索 ⇔ 立証の双方向遷移（`B`/`Esc` キー、現場調査に戻るボタン）、ゲームオーバーからの探索再開導線を常備。
- **前提条件ガード**: 証拠3件が揃うまで立証ボタンは非表示・非活性。ロジック層でも二重ガード。
- **ゼロ重なりピン配置**: 全ピン座標はユークリッド距離20%以上離し、同一列の重複配置ゼロ。
- **スマホレスポンシブ**: `position: fixed`、`100dvh`、`clamp()`、`env(safe-area-inset-bottom)` 対応。
- **SonarQube / Biome品質**: 認知複雑度15以下、`Number.parseInt`、標準CSS構文を遵守。
