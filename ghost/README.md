### 生成とループ加工（2026-10-26）

- Flow Music（Lyria 3.5）でインストゥルメンタル4曲を生成。生成側は BPM・尺の指定を厳密には守らないため、長めに生成して後加工で切り出す前提とする。
- 切り出しは検出テンポの小節グリッドで安定区間を選び、末尾→先頭の等パワークロスフェードでシームレス化。ラウドネス -16 LUFS / トゥルーピーク -1.5、MP3 192kbps に統一。
- 継ぎ目は波形指標（サンプル段差・前後音量比・スペクトル不連続）だけでは不十分なため、記号解析でも検証する。librosa のクロマ（音高クラス）による「末尾の和音→先頭の和音への後続妥当性」と、Basic Pitch で MIDI 化したノート列の支配音を確認し、コード進行が循環しない区間は採用しない。
- `bgm_truth.mp3` は当初区間でコードが循環しなかった（末尾 E 系 → 先頭 D 系）ため記号解析で切り直し、その後「無音の箇所でつなぐ」方針で全編アーク版に変更した。フェードアウトして無音になる曲尾（169秒以降 RMS 0.005 以下）から、無音で始まる曲頭へ接続し、継ぎ目の音量は本編比で約1/30。1周ごとに導入→本編→ブリッジ→フェードアウトという曲全体の流れを含む。
- 2026-10-27 に `docs/bgm-production-guide.md` の手順で残り3曲を再検証。`bgm_investigation.mp3` は記号解析＋位相合わせで一度切り直し（39.33秒〜・80拍）、さらに「無音でつなぐ」全編アーク版（曲頭約16秒・曲尾約10秒の無音で接続）も試したが、本作はシーンごとに BGM を切り替える方式のため、冒頭の長い無音は「切り替えても無音が続く」問題になり不採用。最終版は、本編内にある約4秒の音量ディップ（31.9〜36.2秒、フレーズの谷間）の出口を継ぎ目にした区間ループ（35.91秒〜・80拍、45.4秒）。冒頭から音が鳴り、継ぎ目では1拍だけ音量が落ちてすぐ本編に戻る。`bgm_title.mp3` と `bgm_crisis.mp3` は候補区間を同手順で作って比較した結果、現行版が全指標で最良だったため据え置き（title: クロマ距離 0.003、crisis: 後続妥当性 0.006・不連続比 0.53）。

### 再生方式（`ghost/js/audio.js`）

- BGM は `decodeAudioData` で `AudioBuffer` 化し、`AudioBufferSourceNode`（`loop=true`、`loopEnd=buffer.duration`）でサンプル精度のギャップレスループ再生とする。`HTMLAudioElement` の `loop` はシーク境界で一瞬の無音が生じるため、BGM ではフォールバック専用とする。
- 曲切替時の非同期ロード競合はセッション ID で防止し、画面が非表示になったら `AudioContext` を suspend、復帰時に resume する。音量は `GainNode` で制御。
- セリフボイス（Web Speech API）とは独立した経路であり、BGM 側の都合でボイスを止めない。SE は `assets/audio/sfx_*.mp3` を使い、読み込めない場合はプロシージャル合成（`playSynthSe`）へフォールバックする。
