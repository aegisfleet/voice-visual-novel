# GHOST PROTOCOL 〜26,739台の亡霊と能動的サイバー防御・発動第1号〜

2026年10月に発生した「お名前.com デスクトップクラウド（FX自動売買向けWindows VPS）」に対する大規模サイバー攻撃事件（26,739台侵害・国内外70超の証券/FX口座不正操作・能動的サイバー防御の措置要請第1号）を徹底取材・構造解析し、**全5章＋プロローグ＋エピローグの長編インタラクティブ・サイバーサスペンス小説**として再構築した体験型コンテンツです。

## 特徴：小説を読み進めながら真実にたどり着く「章進行型インタラクティブ・ノベル」

従来の「最初から1画面に6個の証拠ピンが並び、総当たりでクリックするだけ」のプロトタイプ構成を抜本的に刷新し、**事件の発生から国家の反撃までを時系列（全5章）で追体験するノベル主導型のゲーム構造**へと進化しました。

1. **時系列・全5章のインタラクティブ小説進行**
   - 各章の冒頭で、緊迫した長編ノベルパート（ナギサ ケイ・アリア・タカミヤ レン・クロダ統括官・ミオ分析官の群像劇）が展開されます。
   - その章の物語で浮かび上がった「現実の事件の謎」を解明するため、章ごとにターゲット表示されるフォレンジック鑑識スポットを調査し、章末の推論ゲートで真相を立証することで次の章へと物語が進みます。
2. **「全編小説＆事件真相レポート」リーダーモード（`📖 小説版` / `READ FULL NOVEL & REPORT` ボタン）**
   - タイトル画面や上部HUDの「📖 小説版」ボタン（またはキーボードの `N` キー）から、**プロローグ〜全5章〜エピローグの小説テキスト全文と、各章で暴かれた現実のインシデント構造解説レポート**を、いつでも一つの長編小説として通読・章別閲覧できます。
3. **現実のサイバー攻撃・制度設計の深層を完全網羅**
   - **Chapter 1（10/19〜10/21）**：なぜ攻撃者は資金を自分の口座へ盗み出さず、わざわざ高スプレッド往復注文（`DEMOFASTLOSS`）で顧客の口座残高を「溶かした」のか？（証券口座の出金名義一致制限と、顧客資産を人質にしたインフラ事業者への恐喝構造）
   - **Chapter 2（10/22）**：なぜ第2報の指示通りにパスワードを変更したのに不正取引が止まらなかったのか？（MT4/MT5の既存認証済みソケット維持仕様と、攻撃者『Hacking Team』による丁寧な日本語メールを使った被害者・企業の分断工作、WPS Office中国語メタデータによる多国籍偽旗工作）
   - **Chapter 3（10/23）**：なぜマルウェアが一切検出されない被害者の「自宅PC」から4,352個のファイル（ブラウザの`Login Data`等）が抜かれたのか？（2019年配布の`.rdp`ファイルに潜んでいた`drivestoredirect:s:*`設定と、`\\tsclient\C`によるリバースRDP侵害）
   - **Chapter 4（10/24 AM）**：四重恐喝（口座破壊・自宅PC暴露・ランサムウェア・内部情報公開）をどう無力化したのか？（第4報における「攻撃者への支払ゼロ」「約款免責を超えた顧客実損100%直接補償＋全員への見舞金5,000円＋6ヶ月無償移行」というゲーム理論的逆転劇と、閲覧専用Investor Passwordによる客観的損害算定）
   - **Chapter 5 & Epilogue（10/24 PM〜10/25未明）**：2026年10月1日施行「能動的サイバー防御法（サイバー対処能力強化法）」における**発動第1号要請と制度上の3つの壁**（①民間からの直接申請制度の不在と基幹インフラ15分野の壁→警察官職務執行法第6条の2による職権認知、②2027年秋まで未施行の無同意通信取得の壁→被害企業による100%任意ログ提供、③外国主権と偽旗工作の壁→`\\tsclient\C`侵害時にアリアが仕込んだカナリアトークンによる真のC2発信源特定）および政府の「手の内を明かさない」非公然アクセス・無害化措置。

## ディレクトリ構成

- `ghost/index.html` - 5章タイムラインバー・小説リーダーモーダル搭載メインUI
- `ghost/css/style.css` - サイバーサスペンスUI＆章進行ハイライト・小説リーダー用スタイルシート
- `ghost/ghost_scenario.json` - 全5章シナリオ・6大フォレンジック証拠・推論問答マスターデータ
- `ghost/js/scenario.js` - ブラウザ直接実行用シナリオバンドル
- `ghost/js/character.js` - 登場人物（ナギサ ケイ・アリア・タカミヤ レン・クロダ統括官・ミオ分析官）定義
- `ghost/js/state.js` - 章進行（Chapter 1〜5）・証拠収集・セーブ状態管理エンジン
- `ghost/js/app.js` - 章別ノベル再生・小説全文リーダー・推論ゲート制御コントローラー
- `ghost/js/audio.js` - Web Audio API によるBGM/SEプロシージャル合成およびWeb Speech API音声合成
