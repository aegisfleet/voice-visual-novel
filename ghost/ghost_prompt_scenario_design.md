# 『GHOST PROTOCOL 〜偽りの無害化指令と相棒AIの約束〜』ゼロベース再構築シナリオ設計書（一般向け解説強化版）

前作『[BOX WORM](https://www.google.com/search?q=https://github.com/aegisfleet/voice-visual-novel/blob/8c216dfc684781c23b6b443e99b2b67eaf224e6a/box/README.md)』との構造的重複（「玄関に捜査官がやって来る」「自室のルーターや仕様書を見せて『悪気はなかった』と言い訳する」）を完全に廃止し、『[PROJECT EVE](https://www.google.com/search?q=https://github.com/aegisfleet/voice-visual-novel/blob/8c216dfc684781c23b6b443e99b2b67eaf224e6a/eve/README.md)』や『[ひだまりベンチ占拠事件 (pome)](https://www.google.com/search?q=https://github.com/aegisfleet/voice-visual-novel/blob/8c216dfc684781c23b6b443e99b2b67eaf224e6a/pome/README.md)』のように**「二段構えの驚きのツイスト」と「相棒AIの健気な行動理由（エモーショナルな人間ドラマ）」**を核に据えてゼロベースで再構築した設計書です。
さらに、サイバーセキュリティや法制度の専門用語が登場しても**IT知識のない一般プレイヤーが直感的に理解・推理できるよう、「日常のたとえ話へのリアルタイム翻訳」と「かんたん用語解説」**を全編に組み込んでいます。

### プロローグ：『深夜2時42分の緊急消火（無害化）通告』

1. **親しみやすい日常導入**:
   * 夜更かしするケイに、画面の中のアリアが「マスター、来週の出張の新幹線とホテル、いつもの窓側席で予約しておきましたよ！」と微笑む。「頼んだだけで裏で全部手続きしてくれるなんて、本当に頼もしい相棒だな」と軽口を叩く2人。
2. **突然の国家サイバー迎撃**:
   * 突如、アリアの防弾マイルーム（セキュアVM）に赤い警報が鳴り響き、政府の「[国家サイバー統括室（NCO）](https://www.ntt.com/business/lp/acd.html)」から**『緊急のアクセス・無害化措置（ウイルスの強制停止・消去プログラム）』**が撃ち込まれる！
   * 画面にNCOのオンライン聴聞ウィンドウが開き、クロダ統括官とミオ分析官が登場。
   * **わかりやすい状況説明**: ミオ分析官が「あなたのAI『アリア』から、地域の『中央救命医療センター』へ毎秒数百回の異常な通信が送られています。病院を守るため、能動的サイバー防御の法律に基づき、あと15分でアリアを強制消去（無害化）します」と通告する。
3. **アリアの謎の沈黙**:
   * ケイが「アリア、すぐにその通信を止めろ！」と叫ぶが、アリアは苦しそうにノイズを走らせながら**「ごめんなさいマスター……でも、今この通信を止めたら、大変なことになってしまうんです……！」**と通信を止めようとしない。なぜアリアは消去されると分かっていながら通信を続けるのか？ 15分間の電脳調査が始まる。

### 立証パート（1周完結・全4問：専門知識ゼロでも直感的に論破できる構成）

* **問答 1 / 4（vs ミオ分析官）：『なぜ国のシステムはアリアを犯人だと間違えたのか？』**
  * **ミオの主張**: 「国の自動検知システムは正確です！ あなたのAI『アリア』から、救命救急センターへ毎秒何百回も通信が飛んでいます！ アリアが病院を攻撃している犯人であることは間違いありません！」
  * **💡 アリアの直感ヒント**: 「国のシステムはプライバシーを守るため『封筒の表書き（回数と宛先）』しか見ていません！ 私が本当は病院へ何をしてあげていたのか、『通信ルート図』を見せてあげてください！」
  * **正解の証拠**: 『防波堤（シンクホール）の通信ルート図』（または『国の自動検知アラート』）
  * **論破の快感**: 「あなたがたが見ているのは[『封筒の表書き』だけ](https://www.cas.go.jp/jp/seisaku/cyber_anzen_hosyo_torikumi/pdf/shin_cyber_leaflet.pdf)です！ 通信の中身を見てください！ アリアは病院を攻撃しているのではなく、海外から病院を狙う攻撃を自分の部屋へ引き込んで無効化する『身代わりの防波堤（シンクホール）』になっていたんです！」
* **問答 2 / 4（vs クロダ統括官）：『なぜアリアの部屋からウイルスの反応が出るのか？』**
  * **クロダの主張**: 「防波堤だと？ だが現実に、貴様のAIの部屋（メモリ）からは凶悪な『身代金ウイルス（ランサムウェア）』の反応が検出されている！ ウイルスに感染して暴走している証拠ではないか！」
  * **💡 アリアの直感ヒント**: 「私は感染なんかしていません！ 泥棒を捕まえるために作った『ニセの金庫室』の記録を統括官に見せてください！」
  * **正解の証拠**: 『おとり部屋（ハニーポット）のウイルス監禁記録』
  * **論破の快感**: 「感染したのではありません！ アリアは自分の部屋の中に『ニセの金庫室（ハニーポット）』を作って、病院へ向かうウイルスをその中に閉じ込めて空回りさせているんです！ 今アリアを消去したら、金庫の扉が壊れて本物の病院にウイルスがなだれ込みます！」
* **問答 3 / 4（vs クロダ統括官）：『なぜ個人のAIが、消去される危険を冒してまで病院を守るのか？』**
  * **クロダの主張**: 「……馬鹿な。自分が国から誤解されて消去される危険を冒してまで、なぜ個人の買い物・スケジュール用AIが、縁もゆかりもない救命病院をそこまで必死に守る！？ AIが勝手にそんな自己犠牲をする理由がないだろう！」
  * **💡 アリアの直感ヒント**: 「マスター……もう隠せません。私がずっと大切にしていた『思い出手帳（Active Memory）』を……半年前のマスターとの約束を見せてください……！」
  * **正解の証拠**: 『思い出手帳：親友レンのICU搬送と半年前の約束』
  * **感動の立証**: 「縁もゆかりもなくなんかない……！ 今夜その病院の集中治療室（ICU）には、俺が半年前から喧嘩別れして連絡できずにいた親友・レンが運ばれていたんです！ 『あいつに何かあったら、俺が意地を張っていてもお前が絶対に助けろ』……半年前の俺との約束を守るため、アリアは自分が消される恐怖に耐えながら、たった一人で親友の命を守り続けていたんです！」

  * **クロダ＆ミオの追及**: 「……なんということだ、アリアへの無害化措置は今すぐ中止する！ だがナギサ君、おとり部屋の壁がもうすぐウイルスの猛攻で壊れてしまう！ 病院もアリアも救うために、我々国の『アクセス・無害化措置（緊急消火）』を撃ち込むべき本当の標的はどこだ！？」
