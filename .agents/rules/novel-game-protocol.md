# ワークスペースルール: Webノベルゲーム開発プロトコル

本リポジトリで作業するすべてのAIエージェントは、以下のルールを厳格に遵守すること。

## 1. 必読ドキュメント
開発や改修の着手前に、必ず以下の2つのドキュメントを参照せよ：
- [docs/novel-game-implementation-guidelines.md](file:///d:/Work/voice-visual-novel/docs/novel-game-implementation-guidelines.md)
- [docs/agent-novel-game-dev-protocol.md](file:///d:/Work/voice-visual-novel/docs/agent-novel-game-dev-protocol.md)

## 2. 厳格遵守事項
1. **ステートの可逆性と詰み防止**:
   - 探索から立証・論戦へ進んだ後でも、必ず「🔍 現場の再調査に戻る」ボタンおよびショートカット（`B` / `Esc`）で戻れるようにすること。
   - ゲームオーバー時も「現場に戻って証拠を探し直す」導線を常備すること。
   - 証拠不足など前提条件未達時にアクションボタンを表示・活性化させないこと。またロジック層でも二重ガードすること。
2. **物語体験とカタルシス**:
   - プレイヤーが正しい証拠を提示して勝利した直後に、理由のないBAD ENDに落とさないこと。
   - 事件解決の会話劇（潔白の証明、相手の納得、仲間の安堵）を描写し、段階的解決（NORMAL END）を経て次フェーズ（Phase 2）へ接続すること。
3. **UI/UXとレスポンシブデザイン**:
   - カットインやダイアログの文字サイズには `clamp()` を使用し、幅360px〜380pxの極小スマートフォン画面で見切れないこと。
   - 探索ピンは同一画面内で20%以上の距離を離し、絶対に重ならないよう配置すること。
   - タップターゲットは44px以上を確保すること。
4. **CSS設計の規約**:
   - グローバルに `.hidden { display: none !important; }` を適用し、セレクタ漏れによる表示バグを防止すること。
   - アニメーション再トリガー時はリフロー（`void el.offsetWidth;`）を必ず行うこと。
5. **実機ブラウザ検証の義務**:
   - コード変更後は必ず `browser_subagent` を用い、PC画面（1200x800）とスマホ画面（380x750）の両方でプレイスルーを実行し、スクリーンショットでUI崩れがないことを自ら確認してから完了報告とすること。
